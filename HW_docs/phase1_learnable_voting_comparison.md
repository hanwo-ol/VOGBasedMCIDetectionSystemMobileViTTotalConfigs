# Run 4 기준 보팅 가중치 파이프라인 비교 명세서 (현재 vs 1단계)

---

## 1. Run 4 환경 및 데이터 명세

- **전체 데이터셋**: 37명 (HC 14명, MCI 23명), 총 5,715개 윈도우 통과 (아티팩트 30도 기준).
- **교차 검증 구조**: 15-Fold Stratified Group CV (피험자 누수 없음).
  - **Train**: 25명 (HC 10명, MCI 15명), 약 3,872개 윈도우.
  - **Test**: 12명 (HC 4명, MCI 8명), 약 1,843개 윈도우.
- **현재 보팅 메커니즘 (`_aggregate_subject_prob`)**:
  - 피험자 $s$의 모든 윈도우 $(p_i, t_i)$에 대해:
    $$P_s = \frac{\sum_{i=1}^{N_s} w_{t_i} \cdot p_i}{\sum_{i=1}^{N_s} w_{t_i}}$$
  - $w_t$: `--vote-weights "0.0 0.5 0.5 1.0 0.0 1.5 1.5 3.0"`로 고정된 상수.

---

## 2. 1단계(Phase 1) 데이터 흐름 및 알고리즘

### 2.1 학습 및 검증 단계 (Train & Validation)

#### 문제점: 훈련 데이터 오버피팅 확률 직접 사용 불가
- 훈련 25명의 윈도우를 MobileViT에 넣으면 예측 확률이 0 또는 1에 극단적으로 치우쳐져 있어, 이 확률로 가중치를 최적화하면 특정 과제 1개에 가중치가 100% 쏠리는 현상 발생.

#### 해결 방안: 훈련 셋 내 2가지 현실적 가중치 결정 옵션

```
[Fold k 시작]
   │
   ├─ 1. MobileViT 모델 학습 (Train 25명 / 3,872 윈도우)
   │
   ├─ 2. 훈련 셋(Train 25명) 내부에서 가중치 w_0 ~ w_7 산출
   │     │
   │     ├─ [옵션 A: 성능 지표 기반 소프트맥스 매핑]
   │     │   - 25명 데이터에서 8개 과제별 단독 검증 지표(AUROC_t) 계산
   │     │   - w_t = exp((AUROC_t - 0.5) / tau) / sum(exp((AUROC_j - 0.5) / tau))
   │     │
   │     └─ [옵션 B: Ridge 규제 로지스틱 회귀 (Stacking)]
   │         - 25명의 8개 과제별 평균 확률 행렬 X in R^{25x8} 생성
   │         - 레이블 Y in {0,1}^{25}에 대해 L2 규제 로지스틱 회귀 학습: w* = argmin ||Y - sigma(Xw)||^2 + lambda ||w||^2
   │         - w*를 양수 제약 및 합=1로 정규화 (Softmax 또는 L1 정규화)
   │
   └─ 3. 도출된 w_0^* ~ w_7^* 동결(Freeze)
```

---

### 2.2 테스트 단계 (Test)

1. Fold $k$의 테스트 피험자 12명(1,843개 윈도우)을 학습된 MobileViT로 추론.
2. 각 윈도우 $i$의 모델 출력 $p_i$와 과제 인덱스 $t_i$ 획득.
3. 2.1단계에서 동결된 $\mathbf{w}^{(k)*}$를 적용하여 피험자 최종 확률 계산:
   $$P_u = \frac{\sum_{i=1}^{N_u} w_{t_i}^{(k)*} \cdot p_i}{\sum_{i=1}^{N_u} w_{t_i}^{(k)*}}$$
4. 12명 피험자의 실제 레이블과 $P_u$를 비교하여 Fold $k$의 최종 AUROC, Acc, Sens, Spec 산출.
5. 테스트 피험자 12명의 데이터는 $\mathbf{w}^{(k)*}$ 결정에 일체 관여하지 않음 (완전 격리).
