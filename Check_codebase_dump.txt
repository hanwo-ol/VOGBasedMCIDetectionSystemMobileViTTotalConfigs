Sheet: 웨이블릿

Row  1: Morlet 웨이블릿(Complex Morlet Wavelet, `cmor4.0-1.0`) 차용의 수학적·신호처리적 타당성과 근거, 그리고 코드베이스 내 구현상의 한계점은 다음과 같습니다.
Row  2: ### 1. Morlet 웨이블릿의 수학적 정의
Row  3: 코드베이스([data_engineer.py:L98](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L98))에서 호출하는 `cmor4.0-1.0`은 복소 모를레(Complex Morlet) 웨이블릿입니다:
Row  4: $$\psi(t) = \frac{1}{\sqrt{\pi f_b}} e^{2\pi i f_c t} e^{-\frac{t^2}{f_b}}$$
Row  5: - **$f_b$ (Bandwidth parameter)**: `4.0` (가우시안 윈도우의 감쇠 속도 및 대역폭 결정)
Row  6: - **$f_c$ (Center frequency)**: `1.0 Hz` (중심 진동 주파수)
Row  7: 푸리에 변환 영역에서의 표현은 다음과 같습니다:
Row  8: $$\hat{\psi}(\omega) = e^{-\pi^2 f_b \left(f - f_c\right)^2}$$
Row  9: ### 2. 차용의 신호처리적 타당성 (이유)
Row 10: #### (1) 하이젠베르크 불확정성 한계 최소화 (Optimal Time-Frequency Localization)
Row 11: - 신호 처리 이론상 시간 폭($\sigma_t$)과 주파수 폭($\sigma_\omega$)의 곱은 다음 불확정성 원리를 만족해야 합니다:
Row 12: $$\sigma_t \sigma_\omega \ge \frac{1}{2}$$
Row 13: - Morlet 웨이블릿은 가우시안(Gaussian) 포락선에 복소 정현파(Complex sinusoid)를 곱한 구조(Gabor 웨이블릿의 일종)이므로, 등호($\sigma_t \sigma_\omega = \frac{1}{2}$)를 만족하는 최소 불확정성 기저 함수(Heisenberg-Gabor Limit)입니다.
Row 14: - 단속적이고 비정상적(Non-stationary)인 안구 위치 오차 신호에서 시간적 발생 시점과 주파수 성분을 왜곡 없이 동시 국소화하는 데 사용됩니다.
Row 15: #### (2) 복소수(Complex) 형태를 통한 순수 순시 진폭(Magnitude) 추출
Row 16: - 실수 웨이블릿(예: Ricker/Mexican hat, Daubechies, Haar)을 연속 웨이블릿 변환(CWT)에 적용하면 기저 함수의 진동에 의해 계수에 제로 크로싱(Zero-crossing) 간섭 및 음수 값이 발생합니다.
Row 17: - 복소 모를레 웨이블릿은 실수부($\text{Re}$)와 허수부($\text{Im}$)가 힐베르트 변환 관계($90^\circ$ 위상차)를 이루므로, 진동에 독립적인 순시 포락선(Instantaneous Envelope)을 다음과 같이 스무딩 없이 직접 산출합니다:
Row 18: $$M(t, f) = \sqrt{\text{Re}(\mathcal{W}[x](t, f))^2 + \text{Im}(\mathcal{W}[x](t, f))^2}$$
Row 19: - 코드베이스([data_engineer.py:L182, L435](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L182,L435))가 2D 흑백 이미지(스칼로그램)로 변환할 때 실수/허수 간섭 패턴 없이 에너지 크기 분포만을 맵으로 구성할 수 있는 수학적 이유입니다.
Row 20: #### (3) 스케일-물리 주파수 간 직접 선형 매핑
Row 21: - 중심 주파수가 $f_c = 1.0\text{ Hz}$로 설정되어 있어, 웨이블릿 스케일 $a$와 실제 물리적 주파수 $f$ 사이의 관계가 역수 형태로 직결됩니다:
Row 22: $$f = \frac{f_c}{a \cdot \Delta t} = \frac{f_s}{a}$$
Row 23: - 샘플링 주파수 $f_s = 120\text{ Hz}$ 환경에서 목표 주파수 $15\text{ Hz} \sim 60\text{ Hz}$에 대응하는 스케일 벡터 $a$를 산출하는 과정([data_engineer.py:L170](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L170))이 수치적 보정 계수 없이 일치합니다.
Row 24: #### (4) 안구 운동(Oculomotor) 신호와의 형상 적합성
Row 25: - 사카드 안구 운동 중 발생하는 미세진전(Ocular Microtremor) 및 사카드 감속기 진동(Post-saccadic glissade/oscillation)은 감쇠하는 유사 정현파(Damped sinusoidal wave) 형태를 띱니다.
Row 26: - 기저 함수의 파형이 신호의 물리적 진동 형태와 가장 높은 상호상관(Cross-correlation)을 나타내어 웨이블릿 계수 응답이 극대화됩니다.
Row 27: ### 3. 코드베이스 구현상의 한계점 및 비타당 요소
Row 28: Morlet 웨이블릿 차용 자체는 표준적인 기법이나, 코드베이스의 세부 설정에는 검증되지 않은 매직 넘버와 처리 누락이 존재합니다:
Row 29: 1. **대역폭 파라미터($f_b=4.0$) 최적화 부재**:
Row 30: - $f_b$가 커질수록 주파수 분해능은 높아지지만 시간 분해능은 저하됩니다($\sigma_t \propto \sqrt{f_b}$).
Row 31: - $4.0$이라는 수치가 120Hz VOG 데이터에서 그리드 서치나 시간-주파수 해상도 최적화 실험을 거쳐 도출된 근거가 코드 및 문서상에 없습니다.
Row 32: 2. **영향 원추(Cone of Influence, COI) 배제 누락**:
Row 33: - 웨이블릿의 가우시안 꼬리(Tail)로 인해 $1.0$초 윈도우의 시작점($t=-0.2\text{s}$)과 끝점($t=0.8\text{s}$) 부근에서 제로 패딩으로 인한 경계 아티팩트(Edge effect)가 필연적으로 발생합니다.
Row 34: - 코드베이스에서는 COI 영역을 마스킹하거나 제거하는 과정 없이 $32 \times 32$ 맵 전체를 그대로 백본 네트워크에 공급합니다.

Row  1: Z-Score 정규화(`(mag_db - mean) / (std + 1e-8)`)가 문제가 되는 기술적 이유는 **정규화가 적용되는 범위(Scope)와 그로 인한 정보 소거 현상** 때문입니다.
Row  2: ### 1. 환자-대조군 간 '절대 진폭(Absolute Energy)' 정보 소거
Row  3: - **수식**:
Row  4: $$\mu = \frac{1}{N}\sum_{i,j} X_{i,j}, \quad \sigma = \sqrt{\frac{1}{N}\sum_{i,j} (X_{i,j} - \mu)^2}, \quad Z_{i,j} = \frac{X_{i,j} - \mu}{\sigma + 10^{-8}}$$
Row  5: - **현상**:
Row  6: - Z-Score 정규화가 전체 데이터셋 기준이 아니라, **각 $32 \times 32$ 단일 윈도우(Trial) 내부에서 개별적으로 수행**됩니다 ([data_engineer.py:L187](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L187)).
Row  7: - 그 결과, 모든 윈도우의 스칼로그램은 물리적 진폭의 크기와 상관없이 평균 $\mu = 0$, 표준편차 $\sigma = 1$로 일괄 강제 변환됩니다.
Row  8: - **임상적 문제점**:
Row  9: - 정상 대조군(HC)의 미세한 주시 진동(작은 절대 진폭)과 MCI 환자의 불안정한 주시 오차(큰 절대 진폭) 간의 **스펙트럼 에너지 크기 차이가 소거**됩니다.
Row 10: - 모델은 신호의 실제 크기를 인지하지 못하고, 오직 $32 \times 32$ 맵 내부의 상대적 기하학적 형태(패턴)만 보고 판정해야 합니다.
Row 11: ### 2. 채널 간(Cross-Channel / Cross-Axis) 상대 비율 왜곡
Row 12: - **현상**:
Row 13: - `four_error` 모드는 4개 채널(`LH-TH`, `RH-TH`, `LV-TV`, `RV-TV`)을 사용합니다.
Row 14: - 4개 채널을 묶어서 정규화하지 않고, **채널마다 각각 독립적으로 Z-Score를 계산**합니다 ([data_engineer.py:L437](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L437)).
Row 15: - **신호처리적 문제점**:
Row 16: - 수평(Horizontal) 태스크의 경우, 수평 오차 채널(LH, RH)은 에너지가 크고, 수직 오차 채널(LV, RV)은 에너지가 0에 가까워야 정상입니다.
Row 17: - 그러나 4개 채널을 각각 $Z$-정규화하면, **수직 축의 미세한 센서 잡음(Noise)도 증폭되어 표준편차 1을 갖게 되고, 수평 축의 강한 운동 오차 신호도 표준편차 1로 압축**됩니다.
Row 18: - 작성자 역시 코드 주석([data_engineer.py:L428-L430](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L428-L430))에 이를 명시하고 있습니다:

Row 24: ### 3. 상위 15% 임계화(Percentile 85)와의 비정상적 결합
Row 25: - **코드 구조** ([data_engineer.py:L183-L187](file:///c:/Users/USER/MCI-VOG/src/four_error_using/data_processor/data_engineer.py#L183-L187)):
Row 26: ```python

Row 28: magnitude[magnitude < threshold] = 1e-3
